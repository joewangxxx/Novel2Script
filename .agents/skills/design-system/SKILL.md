# Design System

Use this skill when the parent Orchestrator routes UI or product experience design work.

## Inputs

- `docs/prd/PRD.md`.
- `docs/architecture/` artifacts.
- Existing `docs/design/` artifacts.

## Instructions

- Create or update `docs/design/ui-prompt.md`.
- Create or update `docs/design/tokens.json`.
- Create or update `docs/design/interaction-notes.md`.
- Keep design guidance adapted to the detected frontend stack.
- If no frontend exists, keep guidance stack-neutral and implementation-ready.
- Do not implement UI code.

## Outputs

- UI prompt.
- Design tokens.
- Interaction notes.
