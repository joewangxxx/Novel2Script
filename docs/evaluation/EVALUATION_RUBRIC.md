# 质量评估 Rubric

## 评分方式

每个指标建议使用 0 到 5 分：

- 0：缺失或不可用。
- 1：大量缺陷，无法可靠使用。
- 2：基础结构存在，但需要大量人工修复。
- 3：可用，但存在明显改进空间。
- 4：质量较高，仅需局部修改。
- 5：质量稳定，可进入下一步生产流程。

## 指标表

| 指标 | 定义 | 评分依据 | 证据要求 |
| --- | --- | --- | --- |
| `schema_validity` | YAML 是否符合当前 JSON Schema。 | 必填字段、类型、数组结构、枚举值是否正确。 | 校验器输出、错误路径、错误说明。 |
| `source_coverage` | 剧本元素是否能追溯到原文章节和段落。 | Scene、Beat、Element 的 `source_trace` 覆盖率。 | 覆盖比例、缺失路径、对应原文段落。 |
| `beat_completeness` | Beat 是否包含目标、策略、阻碍、冲突、代价、转折和外化动作。 | 七个核心字段是否完整且具体。 | 缺字段清单、空泛字段清单。 |
| `character_consistency` | 人物行为、动机、关系和语气是否前后一致。 | 是否违背角色圣经或原文事实。 | 冲突位置、角色设定引用、修复建议。 |
| `dialogue_naturalness` | 对白是否自然、可表演，并符合人物语气。 | 是否过度解释、口吻相似、缺少潜台词。 | 对白片段、角色语气说明、建议改写方向。 |
| `pacing_quality` | 场景节奏和信息释放是否合理。 | 是否拖沓、跳跃、缺少转折或冲突过密。 | 场景长度、Beat 数量、转折点说明。 |
| `shootability` | 内容是否可拍摄。 | 心理描写是否被外化，动作、地点、人物是否清晰。 | 不可拍摄片段、外化建议、场景条件。 |
| `rewrite_risk` | 修改建议对作者原意的偏离风险。 | 是否新增设定、改变因果、改变人物关系或主题。 | 风险等级、原文依据、人工确认要求。 |

## 报告要求

质量报告应包含：

- 总分或分项分数。
- 每项指标的证据。
- 明确的问题路径。
- 推荐修复顺序。
- 哪些问题必须人工确认。
